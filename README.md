# uc-trainer-app
µC-Trainer – Lern-App für Arduino &amp; ESP32: Übungen von den Grundlagen bis zum ESP32-Webserver, simulierte Bauteile, Lösungshilfen und Fortschrittsanzeige. Entwickelt für die Technikerausbildung in Elektro- und Automatisierungstechnik. Läuft offline und lässt sich als App auf dem iPad installieren.

## Lern-Trainer (`/lernen/`)
Eigene Lern-App im Unterordner `lernen/`: PDFs und Fotos hochladen → KI-Zusammenfassung und Lernfragen, Lernrunden mit den Reitern Schlecht / Mittelmäßig / Gut, Fortschritt bis 100 % und Probe-Klassenarbeit als PDF. Aufruf: https://xxleft4dead4xx.github.io/uc-trainer-app/lernen/
